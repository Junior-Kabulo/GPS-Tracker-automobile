# GPS Tracker PCB

Custom PCB design for a vehicle tracking system combining GNSS positioning and GSM cellular communication.

## Project Overview

This project aims to develop a compact embedded tracking system capable of obtaining geographic coordinates and transmitting location data through a cellular network.

The hardware integrates a microcontroller, a GNSS receiver, a GSM module, power management circuitry, and antenna interfaces.

## Hardware Components

| Component | Function |
|---|---|
| ESP32-C3-WROOM-02 | Main microcontroller |
| SIM800C | GSM/GPRS communication |
| L76L-M33 | GNSS positioning |
| Power management | Voltage regulation and battery management |

## Main Objectives

- Design a custom PCB using Altium Designer.
- Integrate GNSS positioning and GSM communication.
- Design the power supply and battery backup.
- Consider RF layout and antenna integration.
- Document the design and manufacturing files.
